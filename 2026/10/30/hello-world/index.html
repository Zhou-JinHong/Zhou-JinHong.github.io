学习记录｜AI Agent 与 LLM 概念梳理
整理一下 AI Agent 与 LLM 这两个方向的基本概念，作为后续深入学习的地基。 LLM（Large Language Model）大语言模型，基于海量文本训练、具备强大语言理解与生成能力的模型。核心特点： 通过大规模预训练习得通用语言能力 支持上下文学习与多任务泛化 是当前 AI Agent 的能力底座 AI Agent具备「感知—规划—行动」闭环、能够自主完成任务的智能体。相比单次问答的 LLM，Agent 更强调： 工具调用（Tool Use） 记忆与上下文管理 多步规划与反思 LLM 与 Agent 的关系LLM 提供「大脑」，Agent 在此之上补充工具、记忆与规划，让模型从「回答问题」走向「完成任务」。 后续计划围绕这两个方向，持续记录论文阅读、工程实践与思考。 先把概念理清，再谈实践。
